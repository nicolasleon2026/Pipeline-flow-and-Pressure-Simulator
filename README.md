# Pipeline Flow and Pressure Simulator

A Python application for analyzing incompressible fluid flow in pipeline systems using fundamental fluid mechanics principles. The program implements the Darcy–Weisbach equation and related engineering correlations to calculate key hydraulic parameters, compare multiple pipeline designs, and visualize system performance.

---

## Features

- Calculates 14 essential pipeline flow properties, including:
  - Reynolds Number
  - Darcy Friction Factor
  - Pressure Drop
  - Head Loss
  - Total Dynamic Head (TDH)
  - Flow Velocity
  - Pump Power
  - Flow Rate
  - Pipe Cross-Sectional Area
  - Additional hydraulic performance metrics

- Implements the Darcy–Weisbach equation for pressure loss analysis

- Supports multiple pipe materials and diameters

- Compares multiple pipeline configurations simultaneously

- Automatically generates engineering plots using Matplotlib

- Provides rapid evaluation of alternative operating conditions and system designs

- Laminar and Turbulent Flow
- Darcy Friction Factor
- Pressure Loss in Pipes
- Total Dynamic Head
- Pump Power Requirements
- Fluid Velocity and Continuity
- Pipe Material Effects on Hydraulic Performance

## Example Applications

This tool can be used to:

- Compare different pipe diameters for a pipeline design
- Estimate pressure losses in piping systems
- Evaluate pump power requirements
- Analyze the effect of flow rate on system performance
- Compare different pipe materials and operating conditions
- Visualize hydraulic performance through engineering plots
